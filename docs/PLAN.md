# Claude plan handoff

Read Claude desktop Cowork task “AI hackathon competition idea”, FUTURE//SELF War Room: main sections, all W0/W1/W2/W3/W4/Final panels and handoff prompts. This is a requirements summary, not an implementation claim.

ECHO is a speech-only future-self companion: interview, goals, explicit memory, adaptive missions, evidence-based capacity decisions, and later simulations of possible futures. No typed chat or onboarding forms. Captions show what was heard and what actually changed.

Priority: reliable voice → memory → missions → futures. Premium GPU TTS, screenshot intake and multilingual support are stretches. Scenarios must be labeled as assumptions, not predictions.

The handoff assigns backend/infrastructure to Codex, stage/hologram to Antigravity, and prompts/story/scheduling to Claude. No other agent was launched by this implementation. The first milestone includes an integration UI for testing the backend.

The planned demo goes onboarding → appearance → missions → correction → recovery evidence → futures → recap → forgetting. Current progress covers the local foundation, goals, explicit memory and reversible goal changes only.
